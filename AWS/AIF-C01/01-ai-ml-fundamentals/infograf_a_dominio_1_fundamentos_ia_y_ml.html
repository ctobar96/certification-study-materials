Tarea 1.1

1. Taxonomía e Jerarquía de la Inteligencia Artificial

La Inteligencia Artificial es un dominio amplio con capas concéntricas de especialización. Cada subconjunto resuelve un tipo de problema de negocio específico según los datos disponibles.

Capa 1 (La Más Amplia) Reglas + Algoritmos

Inteligencia Artificial (IA)

Cualquier técnica informática que simule el razonamiento o comportamiento humano (sistemas expertos, lógica difusa y aprendizaje de máquinas).

Capa 2 (Subconjunto de IA) Datos Estructurados

Machine Learning (ML Tradicional)

Algoritmos que aprenden patrones directamente desde datos sin ser programados explícitamente (ej. Regresión Lineal, Árboles de Decisión, Random Forest).

Capa 3 (Subconjunto de ML) Redes Neuronales (ANN)
Deep Learning (DL)

Redes neuronales artificiales profundas compuestas de múltiples capas procesadoras. Excelente para datos no estructurados (visión por computador, audio).

Capa 4 (Núcleo Actual) Creación Sintética
IA Generativa (GenAI)

Modelos de Deep Learning (Transformers, Difusión) capacitados para generar nuevo contenido original (texto, imágenes, código, música) en lugar de solo clasificar o predecir.

Vocabulario Crucial de Examen (AWS AIF-C01)

Feature (Característica)

Variable de entrada medible utilizada por el modelo para calcular una predicción (ej. antigüedad de un vehículo, salario anual).

Label / Target (Etiqueta)

La respuesta correcta u objetivo real que el modelo supervisado intenta predecir (ej. "Fraudulenta", precio final en USD).

Inferencia (Inference)

El proceso en el cual un modelo ya entrenado recibe datos de entrada nuevos y genera predicciones en producción.

Dataset de Entrenamiento

El subconjunto de datos (70-80%) con el cual el algoritmo ajusta sus parámetros internos y aprende patrones.

Dataset de Validación

Datos no vistos durante el entrenamiento empleados para ajustar hiperparámetros y detectar sobreajuste preliminar.

Dataset de Prueba (Test)

Evaluación imparcial e independiente del rendimiento generalizable final antes del despliegue en producción.

Tarea 1.2

2. Paradigmas de Aprendizaje Automático

El método de aprendizaje se selecciona en función de la presencia de etiquetas objetivo y el nivel de interacción requerida con el entorno.

Aprendizaje Supervisado

Datos Etiquetados

El algoritmo aprende a partir de pares de entrada y salida correcta (Inputs + Labels).

Clasificación: Salidas categóricas discretas (ej. Spam vs No Spam, Detección de Fraude).
Regresión: Salidas numéricas continuas (ej. Estimación de precios, proyección de ventas).

Aprendizaje No Supervisado

Sin Etiquetas

El algoritmo descubre estructuras ocultas, agrupaciones o patrones inherentes en los datos.

Agrupamiento (Clustering): Segmentación de clientes según comportamientos (K-Means).
Reducción de Dimensionalidad: PCA para simplificar variables y detectar anomalías.

Aprendizaje por Refuerzo

Recompensa / Castigo

Un Agente interactúa secuencialmente con un Entorno para maximizar una Recompensa acumulada.

Componentes: Agente, Estado, Acción, Entorno, Recompensa.
Ejemplo AWS: Robótica industrial, optimización de logística y AWS DeepRacer.

Distribución de Casos de Uso Empresariales

En las aplicaciones tradicionales de negocios, el aprendizaje supervisado representa más del 70% de las implementaciones activas debido al predominio de tareas numéricas y categóricas.

Clave del Examen: Si en la pregunta mencionan datos históricos etiquetados (ej. "registros de transacciones marcadas como legítimas o fraudulentas"), la respuesta correcta es Aprendizaje Supervisado (Clasificación Binaria).

3. Ciclo de Vida del ML Tradicional, Preprocesamiento & MLOps

El proceso de Machine Learning es iterativo. Incluye la preparación adecuada de datos, mitigación de sesgos y monitoreo continuo en producción.

PASO 1

Definición de Negocio

Convertir un KPI empresarial en una tarea concreta de ML.

PASO 2

Preparación de Datos

Limpieza, One-Hot Encoding, normalización y escalado.

PASO 3

Entrenamiento

Ajuste de parámetros y minimización de función de pérdida.

PASO 4

Evaluación

Medición con dataset de prueba (F1-Score, RMSE).

PASO 5

Despliegue & Monitoreo

Inferencia en tiempo real/lotes y control de derívas.

One-Hot Encoding vs Ordinal

Transforma variables categóricas (ej. ["Rojo", "Verde", "Azul"]) en vectores binarios (0 y 1) para evitar que el algoritmo asuma un orden numérico inexistente.

Fuga de Datos (Data Leakage)

Ocurre cuando información del dataset de prueba o del futuro se cuela en el entrenamiento. Genera métricas engañosamente elevadas que fallan en producción.

Desequilibrio de Clases

Cuando una clase es abrumadoramente mayoritaria (ej. 99% transacciones normales). Se resuelve con Oversampling (SMOTE) o Undersampling.

Deriva de Datos (Data Drift)

Ocurre cuando las propiedades estadísticas de los datos de entrada en producción cambian con respecto a los datos de entrenamiento. Ejemplo: Cambios drásticos en el comportamiento de compra de clientes tras una crisis económica.

Deriva de Concepto (Concept Drift)

Ocurre cuando la relación estadística entre las variables de entrada y la variable objetivo cambia totalmente. Ejemplo: Lo que antes se clasificaba como un patrón de compra normal ahora es una nueva táctica de fraude.

Tarea 1.4

4. Diagnósticos de Ajuste, Matriz de Confusión & Métricas

El balance entre Sesgo (Bias) y Varianza (Variance) define si un modelo padece de Subajuste o Sobreajuste. Comprender la matriz de confusión es indispensable para el examen.

Curva de Diagnóstico: Sobreajuste vs. Subajuste

Al aumentar la complejidad del modelo, el error de entrenamiento cae de forma continua. Sin embargo, si la complejidad es excesiva, el modelo memoriza el ruido y el error de validación vuelve a subir.

Subajuste (Underfitting): Alto error en entrenamiento y validación (Alto Sesgo). Solución: Aumentar la complejidad del modelo o añadir más características.
Punto Óptimo: Mínimo error de validación. Excelente capacidad de generalización sobre datos no vistos.
Sobreajuste (Overfitting): Error casi nulo en entrenamiento pero elevado en validación (Alta Varianza). Solución: Regularización, dropout o reducir características.

Matriz de Confusión & Tipos de Error

Verdadero Positivo (TP) Predicción: Positivo
Real: Positivo
Falso Positivo (FP) Error Tipo I
Alarma Falsa (ej. Spam Falso)
Falso Negativo (FN) Error Tipo II
Peligro (ej. Ignorar Fraude)
Verdadero Negativo (TN) Predicción: Negativo
Real: Negativo

Precisión (Precision): TP / (TP + FP) → Utilizar cuando los Falsos Positivos son altamente costosos.

Exhaustividad (Recall): TP / (TP + FN) → Crucial cuando omitir un caso positivo real es inaceptable.

Comportamiento de Métricas de Clasificación

Comparación de métricas evaluadas sobre conjuntos de prueba balanceados.

Métricas de Regresión & Penalización de Outliers

Para predicciones numéricas continuas, la elección de la métrica define cómo se penalizan los errores extremos o atípicos.

MAE (Error Absoluto Medio): Promedio directo de diferencias absolutas. Fácil interpretación y robusto ante valores atípicos.
MSE (Error Cuadrático Medio): Eleva errores al cuadrado. Penaliza severamente los errores grandes o atípicos.
RMSE (Raíz del Error Cuadrático Medio): Aplica raíz cuadrada al MSE. Vuelve a representar el error en las unidades originales de medida.
